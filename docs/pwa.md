# Installable app (PWA)

Local Shelf installs to the home screen on iOS and Android (and desktop Chromium), opens full screen, and keeps working offline for pages you've opened.

## Pieces

| Piece | Where |
| --- | --- |
| Manifest (name, icons, shortcuts, colours) | `src/app/manifest.ts` |
| Icons and iOS launch screens | `public/pwa/`, generated by `npx tsx scripts/pwa-assets.ts` (also writes `src/lib/pwa-splash.ts`) |
| iOS meta (`appleWebApp`, startup images, `viewportFit: "cover"`) | `src/app/layout.tsx` |
| Service worker | `public/sw.js` (hand-written, served with `no-cache` via `next.config.ts`) |
| Registration, install prompt state, external links | `src/lib/pwa.ts` (imported early by `Hydrated`) |
| Install sheet and Settings "Install app" | `src/components/Install.tsx` |
| Offline pill | `src/components/OfflineNotice.tsx` |
| Back button for the installed app | `src/components/BackButton.tsx` |

Re-run `scripts/pwa-assets.ts` after changing the logo or brand colours. iOS ignores the manifest's `background_color`, so launch screens are images per device size (iPhones portrait, iPads both orientations).

## Service worker rules

Deliberately narrow:

- **Page loads:** network first; the response is returned straight away and cached in the background. Offline: the cached copy, else a self-contained offline page.
- **`/_next/static/*`:** cache first (hashed files). This cache isn't versioned, so an old open tab can still load its chunks after a deploy.
- **`/api/cards`:** network first; each card is also stored on its own so My List can be rebuilt offline for whatever is saved now (marked with `X-Shelf-Offline`, so missing titles aren't reported as gone).
- **Never cached:** App Router flight/prefetch requests (`RSC`, `Next-Router-Prefetch`, `_rsc`), live shelf checks, catalogue search, cross-origin covers.

Any edit to `sw.js` updates the worker (`skipWaiting` + `clients.claim`). Bump `VERSION` only to throw away cached pages and data.

## Install prompt

- **Chromium (Android, desktop):** `beforeinstallprompt` is captured on every device; the sheet's Install button calls it.
- **iOS:** no prompt API, so the sheet shows Share then "Add to Home Screen" steps. Not shown in in-app browsers (Instagram, Facebook…), which can't install.
- **When the sheet appears:** touch devices only, after the welcome is closed and three page views in the session, never over an open sheet, never offline. "Not now" stays quiet for 30 days. Settings > App always offers it.
- The installed app on iOS has its own storage, separate from Safari: My List and settings start fresh. The sheet says so.

## Installed-app (standalone) behaviour

`PREFS_SCRIPT` sets `<html data-standalone>` before paint. In that mode:

- The first-visit welcome is skipped and About's "Show the welcome again" is hidden (`.browser-only`).
- The status bar is `black-translucent` (white text over our content). The header pads itself with `env(safe-area-inset-top)`; on light themes a band in the hero colour sits behind the status bar so it stays readable (`.status-band`).
- "‹ Back" buttons appear on pages that aren't tabs (`.standalone-only`); detail pages show theirs in browsers too.
- Links to other sites open outside the app (a click handler in `pwa.ts`), so you can't get stuck with no back button.
- `<meta name="theme-color">` follows the app theme (`setThemeColor` in `prefs-script.ts`).

## Touch polish

In `globals.css` under "Touch devices and the installed app": no tap highlight, no selection or long-press callouts on app chrome, 16px minimum font in inputs (stops iOS zooming) and press feedback (buttons dim, cards shrink slightly). The `body` rule near the top pads for the notch in landscape.

Title and catalogue sheets slide up on phones, have a grab handle, and close with a downward swipe (`swipeToDismiss` in `Modal.tsx`). Only a mostly vertical downward drag made while the sheet is scrolled to the top counts, and touches from the nested trailer dialog are ignored.

## Testing

- Chrome: Settings shows "Install app" when Chrome considers it installable. Offline: stop the server and reload a visited page and an unvisited one.
- iOS (headless simulator): `xcrun simctl boot <device>`, `xcrun simctl openurl booted http://localhost:3100`, `xcrun simctl io booted screenshot shot.png`. Adding to the home screen needs taps in DeviceHub (Xcode 27's replacement for Simulator.app).
